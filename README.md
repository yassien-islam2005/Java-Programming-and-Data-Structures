## About This Repository

This repository contains my practical work while studying Java programming through Liang's textbook.

The repository is organized by book chapters. Each chapter contains the relevant examples, supporting resources, and selected exercise solutions.

The purpose is to maintain a clear record of my learning process while developing the ability to:

- Understand programming concepts and apply them independently.
- Translate theoretical explanations into working Java programs.
- Analyze program behavior and reason about implementation decisions.
- Experiment with alternative solutions and modifications.
- Solve programming problems using the concepts introduced in the book.
- Develop good programming habits through consistent practice.

This is an evolving learning repository. Its contents will grow as I progress through the book.

## Learning Methodology

My learning process consists of studying the material, implementing examples, experimenting with code, and solving selected exercises.

### 1. Reimplementing Book Examples

I carefully study the examples presented in each chapter and rewrite their code independently.

The purpose is to practice the concepts rather than merely copy and paste the source code.

These implementations help me understand how the concepts introduced in the book work in actual Java programs.

**Important:** The examples in this repository are my own implementations based on my study of the textbook.

### 2. Experimenting and Improving Implementations

While studying the examples, I may modify the original implementations by adding, removing, or changing parts of the code.

Such modifications allow me to investigate different approaches, test my understanding, and explore the behavior of Java programs.

When I make a meaningful modification, I aim to explain the reasoning behind it so that readers can understand what changed and why.

A modification does not necessarily mean that the original implementation is incorrect. Sometimes, it is simply an experiment or an alternative approach.

### 3. Creating Original Examples

In addition to rewriting the examples from the book, I may create my own examples to explore concepts further.

**Original examples that do not appear in the textbook will be identified accordingly.**

This distinction helps readers understand whether an example is based on the book or was created independently as part of my learning process.

### 4. Solving Selected Programming Exercises

Each chapter includes programming exercises designed to reinforce the concepts introduced in the material.

I solve selected exercises that I consider particularly useful for practicing and understanding those concepts.

I do not necessarily solve every exercise in the book. Instead, I focus on selected problems that provide meaningful practice and help strengthen my understanding.

The `Problems/` directory within a chapter contains my solutions to the exercises I have chosen to work on.

These solutions represent my attempts to apply what I have learned and improve my problem-solving skills.
